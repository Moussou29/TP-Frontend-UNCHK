# Reproduction de la page d'accueil de l'UN-CHK

## 👥 Membres du groupe
- NDEYE MOUSSOU CISSE

## 📝 Description du projet
Ce projet a été réalisé dans le cadre du TP de Frontend (Master MICDA 2025-2026). L'objectif était de reproduire l'interface de la page d'accueil de l'Université Numérique Cheikh Hamidou Kane (UN-CHK) en utilisant un framework CSS moderne.

## 🛠️ Technologies utilisées
- **HTML5** : Structure de la page.
- **CSS3** : Styles et animations personnalisées.
- **Bootstrap 5** : Framework CSS pour la grille responsive et les composants (Navbar, Carrousel, Cartes).
- **FontAwesome** : Bibliothèque d'icônes.

## 🚀 Instructions pour exécuter le projet
1. Cloner le dépôt sur votre machine.
2. Ouvrir le fichier `index.html` dans un navigateur web.
3. (Optionnel) Utiliser l'extension "Live Server" sur VS Code pour un rechargement automatique.
